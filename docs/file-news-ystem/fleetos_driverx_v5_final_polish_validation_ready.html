Driver data model

  • driverId: unique DriverX user.
  • officeId: nullable until linked/approved.
  • availabilityStatus: offline, online, busy, onTrip.
  • busyReason: break, fuel, prayer, vehicle, personal, other.
  • vehicleClass: Standard, Comfort, SUV, Van, Luxury, Travel.
  • eligibility: vehicle, office, documents, zone, service class.

Trip data model

  • tripId: dispatch and history ID.
  • serviceClass: selected class from Fleet Ride.
  • pricingType: liveMeter or fixedTravel.
  • paymentMethod: cash, card, wallet, office account.
  • officeManaged: boolean + office details.
  • supportContext: rider, office, route, stage, evidence.

Accessibility acceptance criteria

  • 48 dp minimum tap target.
  • 56–64 dp slide actions.
  • VoiceOver/TalkBack label for every CTA.
  • Slide actions have accessible alternative confirm action.
  • 100%, 115%, 130% text scale with no clipping.
  • Arabic RTL mirrors layout without breaking route data.

QA acceptance criteria

  • iPhone SE and mid-range Android do not crop slide action.
  • Mounted-phone mode keeps map and SOS visible.
  • Outdoor mode route is stronger than default traffic.
  • Busy never receives request cards.
  • Cancel is removed after trip start.
  • Office support appears only when accepted/active.

DriverX Native Map + Outdoor Mode Rules

DriverX must be proven against real Google Maps or Mapbox, not only a CSS mock map. These production tokens define land, roads, routes, markers, POI clutter, traffic, low-light behavior, and navigation visibility.

Native map tokens

Use these values as design tokens in Flutter, Google Maps JSON style, or Mapbox style layers. Outdoor mode strengthens these values only during active driving states.

TokenNormal modeDriving / Outdoor modePurpose
Land color#F3F5F8#EAF0F7Soft, bright surface that keeps route contrast high.
Road color#FFFFFF#FFFFFF + subtle outlineReadable roads in glare without a heavy dark map.
Secondary roads#E7ECF4#D7E0ECEnough separation from land, but not noisy.
Route active#F8A609 / 5–6 px#F8A609 / 7–8 pxOrange is the driver's active work path.
Route outline#FFFFFF / +3 px casing#FFFFFF / +4 px casingSeparates the route from traffic, roads, and labels.
Driver marker48 dp, purple, 10 dp aura54–58 dp, white outline, stronger auraAlways visible from a dashboard-mounted phone.

POI behaviorReduce by 55–70%Reduce by 75–85%Drivers do not need café/shop clutter during navigation.

Driving / Outdoor Mode

Normal mode is calm for parked use. Driving / Outdoor Mode automatically activates during accepted trip, navigation, in-trip, pickup window active, or bright environment detection.

Normal Mode
  • Compact map controls and KPI chips.
  • Route line 5–6 px with white casing.
  • Standard 56 dp slide action.
  • Full status dock and 2–3 KPI chips allowed.
  • Balanced shadows and lower contrast surfaces.
Driving / Outdoor Mode
  • Route line 7–8 px with stronger white outline.
  • Driver and pickup markers increase size and halo.
  • Slide actions become 64 dp and fixed near bottom.
  • Non-critical KPI chips hide during active navigation.
  • Bottom sheet contrast and floating button shadows increase.
